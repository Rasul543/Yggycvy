- 💾 Backup HOME
- 📱 Setup Termux Storage
- 📋 Process Manager

## 📱 Instalasi di Termux

### Cara 1 — Clone dari GitHub

```bash
pkg update
pkg install git
git clone https://github.com/USERNAME/kiietsuu-termux-toolkit.git
cd kiietsuu-termux-toolkit
chmod +x kiietsuu.sh
./kiietsuu.sh
```

Ganti `USERNAME` dengan username GitHub pemilik repository.

### Cara 2 — Menjalankan langsung setelah download

```bash
chmod +x kiietsuu.sh
./kiietsuu.sh
```

## 🔄 Update

Jika repository sudah di-clone:

```bash
cd kiietsuu-termux-toolkit
git pull
chmod +x kiietsuu.sh
./kiietsuu.sh
```

## ⚠️ Catatan

Toolkit ini dibuat untuk penggunaan lokal, administrasi perangkat sendiri, dan pengujian jaringan yang memiliki izin.

Jangan gunakan fitur jaringan terhadap perangkat atau jaringan yang bukan milikmu atau tanpa izin.
